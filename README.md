# 3-2-1, by topic

A personal reading index of James Clear's weekly [3-2-1 newsletter](https://jamesclear.com/3-2-1),
regrouped by theme instead of by date. Every idea, quote and question from the public archive
(August 2019 onward) is tagged with one to three topics, and every entry links back to its original issue.

All text belongs to James Clear and the quoted authors. This is a reading aid, not a republication for profit.

## Files

- `index.html` – the site. Static, no build step, works offline once fonts are cached.
- `data.js` – every entry with its topics, generated by `scripts/build_site.py`.
- `TAXONOMY.md` – the 23 topics and what each one means.
- `tags/*.json` – topic assignments per issue, keyed by issue slug.
- `scripts/` – fetch, parse and build scripts (Python 3, standard library only).

## Rebuilding

```
python scripts/fetch_all.py        # downloads issue pages into issues/ (polite, ~4 min)
python scripts/parse321.py issues  # writes issues.json
python scripts/build_site.py       # merges issues.json + tags/ into site/
```

New issues need tags added to a file in `tags/` before they show up under a topic;
untagged entries fall into "Uncategorised".
